# Fast Food Pablo 🍕

An Italian restaurant website developed as a personal web development project.

## About the Project

Fast Food Pablo is a restaurant website designed to present the restaurant, display its menu, and make contact information easily accessible.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive website design
- Restaurant menu and prices
- Restaurant information and location
- Instagram integration
- Direct phone call button

## What I Learned

- Structuring a website with HTML
- Styling layouts with CSS
- Adding interactivity with JavaScript
- Organizing project files
